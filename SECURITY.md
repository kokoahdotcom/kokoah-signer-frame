# Security policy

This repo holds the code that signs Kokoah users' Hyperliquid trading actions in their browser. Please report suspected vulnerabilities **privately**:

- use GitHub private vulnerability reporting on this repository (Security → Report a vulnerability), or
- email the Kokoah security contact (**TODO: set the real address before launch**).

Please don't open public issues for security problems. Include the affected version (`hello.frameVersion` or the release tag) and steps to reproduce. Never include real private keys, seed phrases or signatures.

What's in scope and how the frame is protected is described in [`docs/THREAT_MODEL.md`](docs/THREAT_MODEL.md).
